# NetlabChronicles
Documentation, configs, code, and diagrams from Netlab Chronicles — an evolving project showcasing real-world SD-Access, SD-WAN, and traditional enterprise network architecture.

## 📚 What’s Inside

This repository contains:

- 📐 **Network Diagrams** – Visual layouts of underlay, overlay, and SDN topologies  
- 🧩 **Configurations** – Sample device configs for SD-WAN, SDA, and classic routing  
- ⚙️ **Scripts** – Automation, setup helpers, and maintenance tools  
- 💻 **Code** – Tools and utilities (e.g., IPAM helpers, config parsers)  
- 🗒️ **Lab Notes** – Planning docs, implementation notes, and troubleshooting tips

## 🔍 Goals

- Build a complete evolving test lab using hardware, virtual form factor, licensed and open-source tools  
- Share insights, configs, and gotchas with other SDN technologies learners
- Track the journey of a real lab as it evolves through CCIE-level preparation

## 📦 Structure

network-lab-docs/
├── diagrams/        # Network diagrams (e.g. .png, .drawio)
├── configs/         # Device configurations for different technologies
├── scripts/         # Shell or PowerShell scripts to help automate tasks
├── code/            # Small tools written in Python or other languages
├── notes/           # Markdown documents with lab planning and notes
└── README.md        # This file

## 🛠 Tech Stack

- Cisco DNAC, SD-WAN (vManage), Catalyst/Nexus  
- Proxmox VE on UCS servers  
- phpIPAM, Cisco ISE, syslog, and more  
- Network automation & tooling with Python, Bash

*Follow the journey. Learn from the build. Netlab Chronicles is just getting started.*
